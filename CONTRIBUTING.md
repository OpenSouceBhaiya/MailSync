# Contributing to MailSync

First off, thank you for considering contributing to MailSync! It's people like you that make the open-source community such a great place to learn, inspire, and create.

We welcome all contributions, from bug reports and feature requests to documentation improvements and code changes.

## 🚀 How Can I Contribute?

### 1. Reporting Bugs
If you find a bug, please help us fix it by reporting it!
- Check if the bug has already been reported in the GitHub Issues.
- If not, open a new issue.
- Please provide as much detail as possible, including your device model, OS version, and exact steps to reproduce the issue.
- You can also report critical bugs securely via our website: [http://opensourcebhaiya.online/bug-report](http://opensourcebhaiya.online/bug-report)

### 2. Suggesting Enhancements
Have an idea to make MailSync even better? We'd love to hear it!
- Open a new issue outlining your idea.
- Explain *why* this enhancement would be useful to the majority of users.

### 3. Code Contributions
Ready to write some code? 
1. Fork the repository.
2. Create a new branch for your feature or bugfix (`git checkout -b feature/amazing-feature`).
3. Make your changes. Ensure your code follows the existing style and conventions.
4. Test your changes thoroughly.
5. Commit your changes with clear, descriptive commit messages (`git commit -m 'Add some amazing feature'`).
6. Push to your branch (`git push origin feature/amazing-feature`).
7. Open a Pull Request!

## 📜 Coding Guidelines
- **Language:** We primarily use Kotlin for the Android app and Vanilla JS/CSS for the extension.
- **Architecture:** Keep the Local-First and Zero-Knowledge principles in mind. Any PR that introduces unnecessary cloud dependencies or telemetry will be rejected.
- **Formatting:** Please ensure your code is clean, readable, and properly indented.

## 🤝 Community
Be respectful, constructive, and kind. We are all here to build something great together.

If you have any questions, feel free to reach out to us at [http://opensourcebhaiya.online/contact](http://opensourcebhaiya.online/contact).

Thank you for helping make MailSync better!
